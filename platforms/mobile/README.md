# Tab Studio — iOS / Android (Capacitor)

Бесплатная версия с рекламой AdMob и аккаунтами Tab Studio. Код приложения общий: `../../app`, настройки: `../../config/tabstudio.config.js`.

```
ios/, android/       нативные проекты
resources/           исходники иконки и заставки
store/               карточка App Store, скриншоты, политика конфиденциальности, app-ads.txt
docs/PUBLISHING.md   пошаговая публикация
```

`npm install && npm run ios` (после `npm install` в корне репозитория).
